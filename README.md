# Anza

Un projet commun de SAUTI et SC Project. Site statique à plat pour GitHub Pages.

## Fichiers
- index.html : page d'accueil
- confidentialite.html, mentions-legales.html, cookies.html : pages légales (FR et EN)
- style.css, script.js
- i18n.js : traductions FR, EN, ES, PT, DE. Langue détectée depuis le navigateur, paramètre ?lang=en possible, choix mémorisé dans le stockage local.
- og-image.png : aperçu pour les partages
- polices Inter auto hébergées, captures webp, logos

## Mise en ligne
GitHub Pages, branche main, dossier racine.
Si l'adresse du site n'est pas https://anza.website/, remplacer cette adresse dans index.html (balises og:url et og:image).

## RGPD
Aucun cookie, aucun traceur, aucune police externe : pas de bandeau nécessaire.
Si un outil de statistiques est ajouté, il faudra un bandeau de consentement et mettre à jour cookies.html et confidentialite.html.
